# Screen Measurement Toolkit 1.0.0

- Dedicated Angle panel: protractor visibility, measurement, rotation, opacity, click-through, reset, clearing and help.
- Shared-vertex O → A → B angle measurement with live pointer preview.
- Translucent 0–180° protractor; original ruler, shape and guide operations preserved.
- Immediate English / Simplified Chinese switching.
- Dual Measure icon and independently named application.
- Feature-based source layout; universal Apple Silicon + Intel app, macOS 13+.

Derived from Distanser by Joel Sandén, under the MIT License. Original copyright and complete MIT text are included in the source, app and DMG.

This build uses an ad-hoc signature and is not Apple-notarized. For an internet download, macOS may require System Settings → Privacy & Security → Open Anyway.
