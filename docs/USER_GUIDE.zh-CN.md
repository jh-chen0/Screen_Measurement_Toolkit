# Screen Measurement Toolkit 使用说明

## 安装与语言

打开 `Screen-Measurement-Toolkit-1.0.0-macOS.dmg`，将 **Screen Measurement Toolkit.app** 拖入 **Applications**。菜单栏会显示工具图标。选择 **Language / 语言 → English / 简体中文**，界面即时切换并保存选择。

新应用使用独立标识 `org.screenmeasurementtoolkit.app`。首次运行会从旧版 Distanser 复制已识别的尺子、导线、形状选择、语言和量角器设置；不写回旧应用。

## 直尺与形状

控制面板有 **Rectangle / Circle / Line / Angle** 四个选项卡。前三项中文为矩形、圆形、直线，保留原始操作：

- 拖动绘制；⌘ 从中心绘制；⇧ 保持 1:1 或直线 45°；⇧⌘ 从中心绘制并保持 1:1。
- 拖动尺子移动，拖末端调整长度，⌘ 拖动零点；右键设置 / 重置零点。
- 导线、十字线、原始透明度和点击穿透保留在原三种模式及菜单中。

## 角度选项卡

选择 **Angle / 角度** 打开专用面板，选择选项卡本身不会捕获屏幕点击。

- **显示量角器**：显示或隐藏半透明半圆量角器。
- **开始测角：O → A → B**：进入三次点击测量。
- **旋转角度 (°)**：输入角度或点步进箭头，以 1° 微调。
- **量角器底色不透明度 (%)**：10–80%，默认 25%，独立于尺子不透明度。
- **量角工具点击穿透**：让量角器和已保存的角度忽略鼠标。
- **重置量角器**：显示量角器并重置位置、大小和旋转。
- **清除角度**：删除本次所有角度测量。
- **量角帮助**：查看完整操作。

菜单栏仍提供相同量角器、两线测角及工具选项，可在不打开控制面板时使用。

## 三次点击测角

1. 点击共用顶点 **O**。
2. 点击端点 **A**，固定第一条线 OA。
3. 移动鼠标，实时预览 OB 与角度；点击 **B** 固定第二条线并保存结果。

鼠标移动或拖动不会保存结果。Esc 或右键取消未完成的测量。显示 OA / OB 的 0–180° 夹角，精度 0.1°；135° 按 135° 显示。

保存后拖 O 调整共用顶点，拖 A/B 调整各自端点；Shift 吸附 15°。拖线或读数条整体移动；复制按钮复制角度，× 删除。角度测量保留在本次运行中，退出后不保存。

## 半透明量角器

双向 0–180° 刻度；每 1°、5°、10° 分别为小格、中格与数字。拖底色、中心 + 或读数条移动；拖 ↻ 旋转；拖 ↔ 或滚轮缩放；Shift 旋转吸附 15°。位置、大小、旋转、透明度及显示状态独立保存。

⌘1–⌘6 为原始工具快捷键，⌘7 显示量角器，⌘8 开始测角，⌘, 打开控制面板，⌘Q 退出。快捷键在应用有焦点或菜单打开时可用，并非全局快捷键。
