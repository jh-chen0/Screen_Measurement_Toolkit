# Contributing

Use the source folders corresponding to the feature being changed. Preserve original ruler gestures and the shared O vertex used by angle rays.

Run `./Tools/check.sh` on a Mac to exercise real controls and interactions. CI runs the computation/migration subset using `--geometry-only`, then builds the universal app and packages the license resources.

Keep the root LICENSE unchanged and update NOTICE for substantial changes. Update product metadata and release notes together when preparing a version.
